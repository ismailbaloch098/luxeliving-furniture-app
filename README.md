LuxeLiving - Native Android Furniture E-Commerce Application

LuxeLiving is a native Android e-commerce application built with Kotlin. Designed using modern software architecture patterns, the application provides a shopping experience for high-end interior furniture, featuring dynamic collection filtering, state management, product model viewing, and an integrated administrative CMS workflow.


Key Features

- Curated Furniture Catalog: Browse curated spaces (Living Room, Bedroom, Dining, Office) with smooth category filtering and real-time product queries.
- Interactive Product Details: High-resolution asset rendering, dynamic color swatches, dimensions, and configurable item specifications.
- Cart and Wishlist Engine: Reactive state management ensuring real-time UI updates for shopping cart totals, wishlist toggles, and checkout flows.
- Integrated Admin CMS: Built-in management interface allowing store administrators to dynamically update product availability, pricing, and catalog models without app redeployment.
- Modern UI/UX: Minimalist aesthetic designed around clean touch navigation.


Technical Stack and Architecture

- Language: Kotlin (100%)
- UI Framework: Jetpack Compose / Android Material Design Components
- Architecture Pattern: MVVM (Model-View-ViewModel) for unidirectional data flow and strict separation of concerns
- State Management: StateFlow / LiveData & ViewModel
- Asynchronous Operations: Kotlin Coroutines & Flow for non-blocking UI interactions
- Testing: Robolectric & JUnit unit testing suite for repository logic and UI state verification


Getting Started and Local Setup

Prerequisites:
- Android Studio (Ladybug / Jellyfish or newer)
- JDK 17+
- Android SDK (API 34+) or an active Android Emulator

Installation Steps:

1. Clone the repository:
   git clone https://github.com/ismailbaloch098/luxeliving-furniture-app.git

2. Open in Android Studio:
   Open Android Studio, select Open, and navigate to the cloned project folder.

3. Build and Run:
   Allow Gradle to sync dependencies, then press Shift + F10 (or click Run app) to launch on your connected device or emulator.
